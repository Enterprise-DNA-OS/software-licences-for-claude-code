# Draft the weekly licence review

Run:

```bash
npm run licences -- weekly-review
```

Replace example names and dates with the operator's actual records. Read before writing. This writes a dated draft from attention, position and renewals. Present the highest priority issues, missing proof and next decisions. It sends nothing.

Use `--json` for machine-readable results. Names match without case sensitivity and IDs can be shortened. An ambiguous match exits with candidates. Ask the operator to choose.
