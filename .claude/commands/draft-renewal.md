# Draft a renewal evidence request

Run:

```bash
npm run licences -- draft-renewal "Product"
```

Replace example names and dates with the operator's actual records. Read before writing. Read the product, entitlements and history. Prepare one draft for human review. It authorises no purchase and sends nothing.

Use `--json` for machine-readable results. Names match without case sensitivity and IDs can be shortened. An ambiguous match exits with candidates. Ask the operator to choose.
