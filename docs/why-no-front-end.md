# Why this desk has no front end

A licence owner needs to reconcile records, explain an exception, prepare a renewal and collect proof. Commands and a database do those jobs. The three read-only HTML reports show the week, positions and removal candidates; the paperwork uses your business name and colours from `brand.json`. There is no web server.

A screen gives guided data entry, drag and drop, phone access and a shared visual workspace. This free version has none of those. It has no offline mobile sync, live discovery agent, software recognition feed, publisher rule library or automatic uninstall. Generated reports are snapshots. A shared database still needs your access controls and backups, and the embedded database is for one operator at a time.
